# 🎤 Voice-to-Voice AI Assistant
An intelligent assistant that converts natural speech into AI understanding and an audio response.

📋 The Three Basic Steps

🎤 User's voice
    ↓
📝 Convert to text (Whisper/Google STT)
    ↓
🤖 Processing using LLM (Cohere API)
    ↓
💬 Generate response
    ↓
🔊 Convert response to speech (pyttsx3)
    ↓
🎵 Play audio to the user
